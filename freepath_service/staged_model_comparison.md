# 暂存增强模型与当前线上模型对比

## 结论

暂存增强模型在两份数据的内插留出测试上均优于当前线上模型；外推模型保持不变。

确认发布前，线上权重仍是当前模型。只有在网页点击“确认更新模型权重”后，暂存模型才会覆盖线上权重。

## 指标对比

| 数据集 | 指标 | 当前线上模型 | 暂存增强模型 | 变化 |
|---|---:|---:|---:|---:|
| data_Al | 内插 SMAPE | 0.808950% | 0.807616% | 下降 0.001334 pct |
| data_Al | 内插 log10 MAE | 0.00385463 | 0.00384629 | 下降 0.00000834 |
| data | 内插 SMAPE | 8.517824% | 8.505308% | 下降 0.012515 pct |
| data | 内插 log10 MAE | 0.03792032 | 0.03785526 | 下降 0.00006507 |
| data_Al | 外推 SMAPE | 10.669601% | 10.669601% | 持平 |
| data | 外推 SMAPE | 21.214517% | 21.214517% | 持平 |

## 暂存模型选择

- `data_Al` 内插：`ensemble_linear_cubic`，`w_cubic = 0.985`
- `data` 内插：`linear`，`smoothing_sigma = 0.3`
- 两份数据外推：继续使用边界留出测试选出的稳定 log 空间线性外推
