### 1. 不透明度自由程：KDTree 局部加权岭多项式

8790 当前只加载 <code>freepath_service/free_path_model_outputs/unified_free_path_model.npz</code>。推理实现是 <code>freepath_service/unified_free_path_core.py</code> 中的 UnifiedModel，Web 入口为 <code>free_path_web_app.py</code>，CLI 为 <code>predict_unified_free_path.py</code>。它不是神经网络，而是在每次查询时用近邻样本拟合一个局部多项式。

![自由程正式模型架构](../output/model-docs/freepath-model-architecture.png)

#### 输入、输出与调用约定

模型输入是 4 个数，不是原始不透明度谱，也不是 FLASH 网格文件：

| 字段 | 含义 | 模型中的数值 |
|---|---|---|
| <code>Z</code> | 原子序数 | 直接输入；实际训练元素仅 4、13、79 |
| <code>rod</code> | 质量密度 | <code>log10(rho [g/cm³])</code> |
| <code>tep</code> | 电子温度 | <code>log10(Te [eV])</code> |
| <code>tgama</code> | 辐射温度 | <code>log10(Trad [eV])</code> |

旧 <code>data.txt</code> 导入器会对前三个物理量取 log10；Be、Al、Au2 标准表中的前三列已经是对数坐标，不能再次取对数。若接入 FLASH，不透明度换算关系为 <code>kappa_R [cm²/g] = 1 / (rho × lnu)</code>。

| 输出字段 | 含义 | 使用方式 |
|---|---|---|
| <code>log10_lnu</code> | 模型直接回归的 <code>log10(lnu [cm])</code> | 用于跨数量级误差、倍数误差和模型诊断 |
| <code>lnu</code> | <code>10^log10_lnu</code>，单位 cm | 物理自由程；接入不透明度计算时使用 |
| <code>artifact</code> | 当前配置的统一模型权重位置 | 用于审计部署配置；它单独不能证明本次结果来自模型，混合/表值路径也可能携带该字段 |
| <code>selected_source</code> / <code>mode</code> | 本次实际选中的表值或模型来源，以及是否属于外推 | 判断请求最终走哪条路径应以这些字段为准 |
| Web 附加字段 | 数据来源、标准表命中、训练域警告、耗时、可选真实程序结果 | 用于审计与安全回退；不是新的预测目标 |

因此，直接调用预测 API 时必须先完成单位统一和 log10 变换；仓库内的 FLASH 接入 helper 可以代做这一步。如果把 <code>rho</code>、<code>Te</code>、<code>Trad</code> 的线性值直接填进 <code>rod</code>、<code>tep</code>、<code>tgama</code>，模型会把它们当作已经取过对数的坐标，结果没有物理意义。

局部模型先用 <code>x'=(x-mu)/sigma</code> 标准化，并额外把 Z 维乘 0.5。对查询点的 520 个近邻采用 <code>w_i=1/max(d_i,1e-10)^p</code>，在以查询点为原点的差分坐标上解带岭惩罚的加权最小二乘；不惩罚截距，截距就是预测值，奇异时回退到最小二乘。

| 路径 | 多项式 | 基函数数 | Ridge alpha | 距离幂 p | 邻居数 |
|---|---:|---:|---:|---:|---:|
| Be、Al及默认路径 | 3 次 | 35 | <code>1e-3</code> | 1.6 | 520 |
| Au / Z=79 | 2 次 | 15 | <code>3e-3</code> | 1.3 | 520 |

唯一的 active 边界专用逻辑是 <code>Z=79 且 rod&lt;-1.87</code>：每条 (tep,tgama) 曲线取低 rod 端 9 点拟合斜率，以 2,500 个邻居、距离幂 1.5 平滑曲线斜率，查询时由 8 条邻近曲线、距离幂 2.0 插值后线性延伸并覆盖基础预测。其他越界输入仍只是裸局部回归，不存在通用 clamp 或可靠回退。

#### 每一步为什么存在

| 处理 | 为什么这样做 | 如果省略或换成更简单做法 |
|---|---|---|
| 对 rho、Te、Trad 和 lnu 使用 log10 空间 | 这些量跨越多个数量级；取对数后，乘法关系和“相差几倍”变成更平滑的加法关系，训练不会被最大数量级样本支配 | 在线性空间最小化平方误差/绝对尺度误差会偏向大 lnu 区域，小 lnu 区域的相对误差可能很大；输出也可能出现非正自由程 |
| 四维标准化 | Z 与三个热力学坐标的数值范围、单位完全不同；KDTree 的欧氏距离只有在尺度可比时才有意义 | 邻居几乎会被数值跨度最大的列决定，所谓“局部”不再代表相似物理状态 |
| 标准化后把 Z 维乘 0.5 | 保留材料差异，同时避免离散 Z 距离完全压过 rho、Te、Trad 的局部结构；0.5 是 active 发布配置，不是物理常数 | Z 权重过大会只按元素分组而忽略状态接近程度；过小又会把不同材料过度混合 |
| cKDTree 查询 520 个邻居 | 先把 29.8 万训练点缩成查询附近的可计算子集，兼顾速度、局部性和拟合稳定性；520 是冻结发布参数 | 邻居太少时局部多项式对网格噪声和奇异点敏感；太多时会把尖峰、谷值和材料局部结构过度抹平 |
| 用“邻居坐标－查询坐标”构造多项式 | 以查询点为原点改善矩阵条件数，而且常数项 beta0 就是查询点预测，不必再代入一次多项式 | 直接在大坐标上展开高次项更容易产生共线性和数值放大，截距也不再等于目标点值 |
| 距离权重 <code>1/d^p</code> | 让更接近查询点的样本贡献更大，同时仍用较多邻居稳定拟合；<code>1e-10</code> 下限避免精确命中时除零 | 所有邻居等权会模糊局部变化；权重无限尖锐则会退化成对单个点或噪声的复制 |
| Ridge 只惩罚非截距系数 | 多项式项高度相关，局部网格还可能近奇异；正则化限制系数爆炸，同时不把目标点的基准值强行拉向 0 | 无正则时系数可在训练邻域内相互抵消、离开邻域后剧烈振荡；若惩罚截距会系统性偏移预测水平 |
| Be/Al 用三次 35 项，Au 用二次 15 项且更强正则 | 从方法作用看，Au 路径自由度更低、收缩更强，可降低高阶项放大尖峰的风险；精确阶数和 alpha 是 active 工件冻结的发布配置 | 所有元素强行共用同一复杂度，会在部分元素上欠拟合、在另一些元素上放大方差；仓库没有逐项消融证明这组数值单独或普遍最优 |
| 仅对 Au 低 rod 做曲线端点扩展 | 局部回归在训练盒外没有两侧邻居，容易回落、变平或振荡；沿固定 (tep,tgama) 曲线延续低密度端趋势，减少无约束高阶外推 | 直接把盒内局部模型用于 <code>rod&lt;-1.87</code> 没有真正插值依据；但该扩展也不严格保证与基础模型数学连续，并且只覆盖这一条已定义边界，不能推广成通用外推保证 |
| high-Z CatBoost wrapper 保持禁用 | 正式 no-op 元数据明确为 <code>route_enabled=false</code>、<code>model_path=null</code>；历史全范围高 Z 路由虽改善旧 Au 随机集，却恶化连续 rod 外推，而且旧 Au/Au2 来源标签存在歧义 | 强行启用历史路由会改变当前正式链，并把旧实验指标、数据版本和当前统一模型混在同一个线上结果里 |

本项目层面的创新不是发明 KDTree、Ridge 或多项式本身，而是把它们组合成一种“查询时局部建模”的可审计代理：权重文件保存训练坐标而非黑盒神经网络；每个点按材料选择局部复杂度；Au 低密度边界再按 (tep,tgama) 曲线处理；最终同时返回物理量、对数量、来源和范围警告。每个查询都要解一个小型线性系统，因此大批量调用应使用 batch/cache；返回的来源与 warning 则供 FLASH 调用方在异常、越界或未训练材料上实施原表回退。

### 2. Z-pinch：log(E) 四阶多项式 Ridge + 物理速度约束

当前 Web 固定加载 <code>zpinch/ai_training_outputs/best_velocity_first_optimized_model_artifact.pkl</code>，正式模型名为 VelocityFirstLogEPoly4RidgeOptimized。训练入口是 <code>zpinch/optimize_zpinch_velocity_first.py</code>，特征与物理包装类在 <code>train_zpinch_surrogate.py</code>，独立推理入口是 <code>predict_current.py</code>。

![Z-pinch 正式模型架构](../output/model-docs/zpinch-model-architecture.png)

#### 输入、输出与真实模型语义

外部调用输入是 6 个数：

| 输入字段 | 单位 | 物理含义 | 在模型中的作用 |
|---|---|---|---|
| <code>I_MA</code> / Web 的 <code>I</code> | MA | 驱动电流幅值 | 表示驱动强度，并参与 <code>I/tr</code> 和电流×半径交互项 |
| <code>tr_ns</code> / Web 的 <code>tr</code> | ns | 电流上升时间 | 区分驱动建立快慢；与半径形成时间—几何交互项 |
| <code>liner_r_cm</code> / <code>liner_r</code> | cm | 套筒半径 | 决定整体几何、间隙和环形面积 |
| <code>foam_r_cm</code> / <code>foam_r</code> | cm | 泡沫半径 | 与套筒半径共同描述相对填充和间隙 |
| <code>m_mg_per_cm</code> / <code>m</code> | mg/cm | 套筒线质量 | 同时进入能量回归和 E↔v 物理换算，必须大于 0 |
| <code>Z_atomic_number</code> / <code>Z</code> | 无量纲 | 原子序数占位字段 | 当前训练列恒为 13，只为未来多材料接口兼容 |

这里必须区分内部训练目标、pickle 输出和网页响应：

| 层次 | 输出 | 含义 |
|---|---|---|
| Ridge 内部目标 | <code>log(E_MJ_per_cm)</code> | 回归器真正学习的稳定正能量表示 |
| 正式 pickle 的 <code>model.predict()</code> | <code>v_cm_per_s</code> | 包装层把正能量转换成带负号的向内速度 |
| Web/API | <code>v_cm_per_s</code> 与 <code>E_MJ_per_cm</code> | Web 先取得 v，再用 <code>E=v²m/(2e16)</code> 反算 E；对训练域内、物理合法且 <code>m&gt;0</code> 的输入，两个输出严格满足同一换算公式 |

所以名称里的 velocity-first 是“artifact 和 API 先输出速度”，并不是底层 Ridge 直接对速度做无约束回归。负号只表示径向向内/内爆方向，速度大小看 <code>abs(v)</code>。

| 类别 | 特征 |
|---|---|
| 6 个基础输入 | <code>I_MA</code>、<code>tr_ns</code>、<code>liner_r_cm</code>、<code>foam_r_cm</code>、<code>m_mg_per_cm</code>、<code>Z_atomic_number</code> |
| 几何派生 | <code>foam_r/liner_r</code>、<code>liner_r-foam_r</code>、<code>π(liner_r²-foam_r²)</code> |
| 驱动派生 | <code>I/tr</code> |
| 交叉项 | <code>I×liner_r</code>、<code>I×foam_r</code>、<code>tr×liner_r</code>、<code>tr×foam_r</code> |

14 维输入经标准化后，<code>PolynomialFeatures(degree=4, include_bias=False)</code> 展开为 3,059 个一次至四次单项式，再由 <code>Ridge(alpha=1e-4)</code> 拟合。外层 TransformedTargetRegressor 学习 <code>log(E_MJ_per_cm)</code> 并用 exp 保证正能量；物理包装层再计算 <code>v=-sqrt(2e16×E/m)</code>。因此 velocity-first 表示 artifact / API 首先返回速度，不是直接对速度做无约束回归；名称中的 optimized 也是固定配置，并未运行网格搜索或贝叶斯优化。

#### 每一步为什么存在

| 处理 | 为什么这样做 | 如果省略或改成普通回归 |
|---|---|---|
| 6 个输入扩展成 14 维 | 半径比、间隙、环形面积、<code>I/tr</code> 和驱动—几何交互是问题结构的显式归纳偏置；其中比值和除法关系不能由有限阶原始变量多项式精确表示 | 只给原始量时，模型要用更高复杂度间接逼近相对尺寸和驱动耦合，小样本下更容易欠拟合或不稳定 |
| StandardScaler | 原始字段约从 0.5 到 600，派生面积和乘积范围更大；先标准化 14 个生成变量，可显著减轻后续幂次和交叉项的尺度失衡，使 Ridge 惩罚更合理 | 大量级字段及其高次幂会支配拟合，矩阵条件数恶化；但要注意 3,059 个展开列本身并没有再次逐列标准化 |
| 14 维做 1～4 阶展开，共 3,059 列 | 用于表示零维响应面可能存在的曲率和多变量交互；多项式推理快速、确定且易打包 | 纯线性/低阶响应面表达能力较弱；但四阶是当前固定经验配置，仓库没有证明它对所有新数据理论最优 |
| <code>include_bias=False</code> | sklearn 的 Ridge 自己拟合截距，避免重复常数列 | 两个常数项会制造冗余和额外共线性 |
| Ridge <code>alpha=1e-4</code> | 最终只有 2,319 个拟合样本，却有 3,059 个展开列，且派生特征高度相关；Ridge 让欠定问题得到稳定解 | 普通最小二乘没有唯一稳定解，高阶系数可剧烈波动，尤其在训练域外迅速发散 |
| 训练 <code>log(E)</code> 并用 exp 还原 | E 必须为正，而且相对/乘性变化在 log 空间更平滑；exp 从结构上保证正能量 | 直接拟合 E 可能给出负数，事后裁剪会在 0 附近造成不连续；若分别独立拟合 E 和 v 两个无约束输出头，还可能破坏二者与 m 的关系 |
| 只学习 E，再由公式生成 v | 数据中的 E 与 v 不是两个独立目标；单目标降低学习任务维度，并强制满足动能关系 | 分别训练能量头和速度头可能返回互相矛盾的结果，例如同一 m 下不满足 <code>E=v²m/(2e16)</code> |
| v 固定取负平方根 | 负号编码向内方向，平方根给出速度大小 | 只回归速度数值可能产生错误正号；只返回绝对值又丢失方向约定 |
| Web 再由 v²反算 E | API 以 velocity-first 为主，同时仍提供能量；反算保证展示值与正式输出来自同一条物理链 | 若 Web 另调一个能量模型或使用另一份舍入值，两个结果会发生漂移 |
| 保留 Z 字段但明确禁用材料外推 | 当前 Z 恒为 13，标准化后该列为 0，所有含 Z 的 680 个四阶展开列都没有可辨识信息；实测改变 Z 不改变输出 | 把接口里可填写 Z 误解成已支持多材料，会制造完全没有训练证据的“材料预测” |

物理换算中的 <code>2e16</code> 来自单位转换：<code>(MJ/cm)/(mg/cm)=1e12 J/kg</code>，再把 m²/s² 换成 cm²/s² 乘 <code>1e4</code>，并保留动能公式中的系数 2：

<code>v_cm_per_s = -sqrt(2e16 × E_MJ_per_cm / m_mg_per_cm)</code>

<code>E_MJ_per_cm = (v_cm_per_s)² × m_mg_per_cm / (2e16)</code>

选择 Polynomial Ridge 而不是更大的神经网络，是因为当前只有 2,730 行、6 个低维基础输入，且数据来自平滑的零维程序表格。这个组合推理快、结果确定，正式 artifact 约 49 KB，并序列化了 sklearn pipeline 和物理包装对象。加载 pickle 时仍依赖仓库中 <code>train_zpinch_surrogate.py</code> 的顶层类与函数，因此迁移时不能只复制这一个文件。它比小样本深网更容易复现和审计，但不能据此宣称神经网络在未来更大、更多材料的数据上一定更差。

本项目层面的创新点是：用物理启发的 14 维表示减少模型“从零猜关系”的负担；用 <code>log(E)+exp</code> 保证正能量；只训练一个能量目标，再包装成 velocity-first 接口并反算一致能量；把预处理、特征顺序、物理包装和划分索引绑定为一个可复现发布链。它是领域约束与经典回归的工程组合，不应表述成一种全新的通用机器学习算法。仓库没有对派生特征、log 目标、四阶展开和物理包装逐项做消融，因此效果只能归因于完整组合，不能声称其中某一个步骤单独贡献了多少提升。

### 3. 脉冲电容：时间顺序评估 + 量化感知混合模型

正式数据来自 <code>pulse_capacitor_online_eval/ceshishuju.zip</code> 中 606 个 OWON SPBXDS 波形文件。每次记录包含 1,520 个 int16 点；采样率由各文件头读取，其中 491 条为 500 MS/s、115 条为 1 GS/s。转换器 <code>tools/convert_owon_spbxds_to_patent_csv.py</code> 按各自采样率生成 606 行 <code>data/raw/ceshishuju_patent_features.csv</code>。这些是 CH1 电流换算的原始采样量，缺少完整探头标定，历史 Voltage* 字段名不能解释成真实端电压或已标定安培。

![脉冲电容正式模型架构](../output/model-docs/capacitor-model-architecture.png)

#### 输入、输出与两级处理链

该模块不是把 1,520 个示波器采样点直接送进神经网络，而是先把每次放电压缩成可解释状态，再做时间序列预测：

| 层级 | 输入 | 输出 |
|---|---|---|
| 波形转换器 | 单个 SPBXDS 文件：1,520 个 int16 CH1 点、文件头采样率、文件名采集时间 | 该次放电的 5 维特征向量 |
| 正式量化感知模型 | 主幅值、过零、反向幅值和系数使用最近 32 次放电的 <code>32×5</code> 窗口；周期还读取前 424 行训练段的有效周期中位数作为冻结参考 | <code>t+20</code> 的 5 维状态向量，不是未来 20 个波形采样点 |
| 8890 报告 API | 已保存的严格评估报告和 606 行特征序列 | 模型排名、验证/测试指标、未来状态、运行时基准和趋势诊断；浏览器再结合用户勾选的特征与阈值计算健康度、有限 RUL 或寿命下限 |

当前 <code>/api/deep-learning-report</code> 读取仓库中已经训练和审计的报告；它不是一个可随意上传新 BIN 后立即在线训练的通用预测端点。新波形需要先运行转换器，再按相同时间划分重训并生成新报告。

| 严格特征 | 提取/含义 | 离散水平数 |
|---|---|---:|
| <code>VoltageMaxRaw</code> | CH1 最大幅值 | 4 |
| <code>VoltageFirstZeroTimeUs</code> | 首次过零时间 | 19 |
| <code>VoltageReversePeakCoefficient</code> | 反向幅值与主幅值关系派生 | 5 |
| <code>VoltageMinAbsRaw</code> | 反向最小幅值绝对值 | 2 |
| <code>DischargePeriodSec</code> | 相邻放电周期 | 155 |

原始波形到五特征的处理及原因如下：

| 处理 | 为什么要做 | 需要注意的边界 |
|---|---|---|
| 以最前 <code>max(20,N/10)</code> 个点的中位数作基线并整段相减 | 去除示波器直流偏置；中位数比均值更不易被预触发尖峰拉动 | 若预触发区本身包含有效脉冲，仍需要现场质检 |
| 去基线后的最大值作为主幅值 | 保留主放电脉冲的强度代理 | CH1 缺完整探头标定，因此仍是电流换算原始采样量，不是端电压 |
| 以 <code>max(1 raw, 主峰×10%)</code> 为脉冲起点阈值，寻找主峰后首次 ≤0 点 | 相对阈值能随幅值变化，1 raw 下限避免阈值退化；过零时间描述放电时序/振荡特征 | 若记录结束前未过零，当前转换器会用末采样点代替，尚未输出单独质量标志 |
| 每个文件按头部采样率把点数换成 μs | 491 条是 500 MS/s、115 条是 1 GS/s，必须逐文件换算 | 强行统一成 500 MS/s 会让 1 GS/s 文件的时间尺度产生约一倍错误 |
| 主峰后最小值取绝对值，并除以主幅值形成反向峰系数 | 同时保留反向振荡的绝对强度和相对比例 | 系数是派生量，后续预测必须与两个幅值保持一致 |
| 相邻文件时间戳之差作为放电周期 | 描述真实试验节拍，而不是波形内部振荡周期 | 首次放电没有前一时刻，CSV 中的 <code>1e-6</code> 只是占位 |
| 无明显反峰时使用 1 raw / <code>1e-6</code> 正值 floor | 保持序列为正，主要用于满足 GM(1,1) 的正序列要求；系数除法另有独立的分母保护 | floor 不是测得信号，也不是健康或失效阈值 |

选择“五个可解释工程特征”而不是直接学习全部波形，是因为当前只有 606 次放电，却有每次 1,520 个采样点且存在两种采样率。特征压缩显著降低维度，也让阈值和寿命结论能追溯到具体波形语义；原始波形端到端模型则会增加学习触发位置、离散 raw 档位和采样率差异等非退化因素的风险。不过仓库没有做端到端波形网络的对照实验，不能据此断言它一定更差。代价是当前方法不会重建完整波形，未被这五项捕获的形状变化也不会进入正式模型。

数据按时间严格划分为第 1–424 行训练、第 425–515 行验证、第 516–606 行独立测试；测试集不参与归一化、早停、窗口或模型选择。在正式 lookback=32、预测 20 步时，监督样本数为 373 / 91 / 91。单特征 <code>NMAE=MAE/训练段特征范围×100%</code>，五项取算术平均；归一化精度定义为 <code>max(0,100%-平均NMAE)</code>。普通 MAPE 会被接近零的真值严重放大，因此不作为主选择指标。

正式量化感知混合模型不是深度网络：主幅值取最近窗口上包络，首次过零取中位数，反向最小幅值取众数，反向峰系数由预测反向幅值/主幅值重建，周期取训练段有效周期中位数。24、32、48 步在验证 NMAE 上完全并列，预先约定的并列规则选择中间值 32。

| 正式输出分量 | 具体规则 | 为什么不用普通连续回归 |
|---|---|---|
| 主幅值 | 最近 32 行最大值，即上包络 | 该特征只有 4 个观测到的离散 raw/量化档位且标定失效方向为上升；均值会生成记录中未出现的中间档位，并可能低估近期高状态 |
| 首次过零 | 最近 32 行中位数 | 19 个离散时间水平；中位数可降低离散采样以及可能的触发抖动或异常过零点的影响 |
| 反向最小幅值 | 最近 32 行众数；并列时取最近出现的并列档位 | 只有 2 个主要档位，更接近状态选择；连续回归通常会给出没有观测意义的档间数值 |
| 反向峰系数 | 由预测反向幅值 / 预测主幅值重建；反向幅值≤1时返回 floor | 避免三个相关量分别预测后出现“系数不等于幅值比”的内部矛盾 |
| 放电周期 | 仅使用训练段中大于 <code>1e-3 s</code> 的有效周期中位数 | 显式排除首次占位；中位数可降低异常间隔的影响，只用训练段也避免验证/测试时间信息泄漏 |

正式远期曲线会把这个稳健五维状态重复到未来各步。也就是说，该模型优先回答“当前可分辨的稳定档位是什么”，不会从量化噪声中凭空制造一条退化斜率；如果真实系统已经进入快速连续退化，这一保守策略也可能反应偏慢。

#### 为什么要做时间划分、训练段归一化和验证选窗

随机打乱会把较晚阶段的离散 raw 档位、试验节拍和潜在退化状态泄漏给训练集，使结果比真实上线更乐观。当前测试的 91 个点是同一条时间序列/本批记录中的滚动目标，不是 91 个独立器件。GRU、LSTM、TCN、Transformer 和 Ridge 的均值、标准差都只由前 424 行计算，避免验证/测试分布反向进入训练；量化混合模型直接在原始档位上工作，不依赖标准化。

五个特征的量纲从约 30,000 到 <code>1e-6</code>，因此不能直接把绝对误差相加。NMAE 用训练段范围归一化后再对五项等权平均，防止主幅值因数值大而独占指标；“归一化精度 89.32%”只是 <code>100%-NMAE</code> 的展示值，不是分类准确率、置信概率或物理波形还原率。普通 MAPE 在 floor 附近会被极小分母放大到数万百分比，所以只作辅助报告。

8 个候选窗口只用验证集选择；24/32/48 完全并列时按预先规则取排序后的中间窗口 32，而不是查看测试成绩后挑一个最好看的窗口。固定时距 20 让所有方法比较同一个 <code>t+20</code> 目标和预测距离；不同候选内部可以直接预测、递推或闭式外推。20 步是工程评估口径，不是由失效机理自动推导的最佳寿命尺度。

本项目层面的创新点是：逐文件采样率感知的波形语义压缩；针对 ADC 离散档位分别采用上包络、中位数和众数；重新构造派生系数以保持多输出一致；让 11 类模型使用同一时间顺序口径竞争，并允许简单稳健模型胜过深网；最后把状态预测和寿命外推分开，证据不足时宁可返回寿命下限。这里的“创新”是针对当前数据的工程设计，不等同于法律意义上的专利新颖性结论。

深度候选都联合输入/输出五个特征，在标准化空间预测“最后值 + 变化量”，输出头零初始化；训练采用 AdamW（lr=1e-3、weight_decay=1e-4）、MSE、全批、梯度裁剪 1.0、最多 250 epoch、验证早停 patience 25，并对种子 11 / 23 / 37 的三个模型取平均。

其他候选方法也在同一时间划分下比较：GM(1,1) 对每个特征做 AGO 与指数响应；持续值保持窗口末值；线性趋势以窗口最小二乘直线外推；阻尼 Holt 在 α∈{0.2,0.5,0.8}、β∈{0.1,0.3,0.6}、φ∈{0.8,0.9,0.98} 中按窗口内一步 SSE 选择；AR(1) 把系数裁剪到 [-1,1]；Ridge 将 L×5 展平后联合预测相对末值的五维增量，并只用 validation 从惩罚 {0.01,0.1,1,10} 中选出最终 10。

| 首次过零 | 0.00184066 μs | 6.5738% | 0.6322% |

最大幅值零误差来自测试段恰好处于量化平台，不能解释成连续模拟量 100% 准确；反向最小幅值仅 2 档，反向峰系数由量化幅值比值派生并只有 5 个水平，两项都明显受 ADC 量化限制。

#### 健康度与剩余寿命为什么要另外门控

健康度/RUL 不是第二个独立神经网络。它把五维状态预测与以下证据组合：首放健康基准、用户选择的失效方向/阈值、每项独立测试 NMAE、最近 120 步可分辨档位数、32/64/120/200 多窗口趋势，以及离散时距回测的最长可信范围。

对每个特征，误差可靠度约为 <code>clip(1-NMAE/100,0,1)</code>，量化分辨率按最近 120 步唯一档位数折算，两者组合成权重。健康消耗只计算“朝失效方向走了阈值跨度的多少”，再用可靠度加权；页面的信息可信度是这些权重的平均值，不是统计置信区间、失效概率或认证结论。

有限 RUL 只有同时满足以下条件才显示：

1. 该特征可靠度至少 35%；
2. 32/64/120/200 四个趋势窗口中至少两个检测到朝失效方向的趋势；
3. 至少一个一致窗口不长于 120 步；
4. 预测阈值交叉不超过已经通过回测的时距；
5. 多项满足时取最早阈值交叉作为限寿项。

这些门槛用于阻止“把 ADC 档位抖动拟合成一条直线，再外推到一个看似精确的失效日期”。如果条件不足，输出的是 <code>RUL &gt; 已验证时距</code> 和总寿命下限，而不是伪造有限寿命。

![脉冲电容多时距可靠性边界](../output/model-docs/capacitor-horizon-validation.png)

多时距独立回测的归一化精度为：20 步 89.3170%、120 步 87.4561%、160 步 83.9925%。规则要求精度至少 85% 且测试点至少 30 个；在 1、5、10、20、40、80、120、160 等离散候选时距中，最远通过门槛的是 120 步（本批序列内部滚动留出），这不表示 1–120 的每一个时距都逐一验证过。

当前页面默认样例没有一致、可检测的失效趋势，结论是“有限寿命暂不可辨识”：剩余寿命只能写 >120 步（以约 5.4 s 中位周期计约 10.8 分钟），总寿命 >726 步；5,000 步只是未验证探索外推，不能当成寿命承诺。

运行时权威健康基准是原始第 1 次放电，周期采用第 2 行首个有效间隔：五项依次为 29,696、0.314 μs、1e-6、1 raw、5.968 s。静态 <code>strict_deep_report.json</code> 仍保留旧的 <code>healthyBaselineRows=32</code> 生成字段，8890 API 会在返回前覆盖这些基准；查看页面结果时应以 API 的 <code>baselineDefinition</code> 和运行时字段为准。

失效试验口径是 606 次观测后再运行 1,500 次失效，总失效行 2,106。只有最大幅值和首次过零两项用该标签反标：29,696 上升 6.98% 得阈值 31,768.7808，0.314 μs 下降 23.32% 得阈值 0.2407752 μs。其余三项没有失效标签标定；当前界面仍给出通用工程默认阈值（反向峰系数下降 5%、反向最小幅值下降 5%、周期上升 20%），被勾选时会参与健康度，满足门控时甚至可能成为 RUL 限寿项。这三项只能作探索性辅助，正式应用应提供经试验标定的阈值，或只使用两项已标定参数；其中 1e-6 与 1 raw 是正值 floor，不是健康阈值。该失效标签用于阈值标定，不能再当独立寿命准确率证据。仓库文档记录了 Theil–Sen 稳健趋势反标方法，但当前没有一支从原始失效序列重新计算阈值的独立脚本；运行时代码使用已离线标定的 6.98% 和 23.32% 常量。
